aplicacion para gestionar llamados de una habitacion a un office de enfermeria, admision u office medico.  
  
1. El sistema debe tener una aplicaccion instalable en android (PSA)

2. La aplicacion habitacion no tiene usuario y clave, pero se configura por variable o archivo de configuracion con clave que habitacion es.

3. cada habitacion esta dentro de un piso y sector

4. la aplicacion de la habitacion puede elegir si llama con un timbre o una videollamada a un enfermero, asistente de calidad o medico

5. la aplicacion debe tener un dashboard con usuario y clave donde una vez iniciada la sesion el usuario puede indicar que piso y sector escucha. ademas que rol va a estar escuchando (enfermero, asistente de calidad o medico)  
  
Infraestructura:  
1. Stack dockerizado con react, Nestjs mongodb con driver nativo
